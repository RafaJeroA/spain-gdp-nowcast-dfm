# Original course submission

`original_course_submission.pdf` is the report originally submitted for the Advanced Time Series course and is preserved unchanged for context.

The GitHub version keeps the same economic specification but cleans the implementation and adds pseudo-out-of-sample evaluation, forecast uncertainty, explicit data-source documentation and a deterministic treatment of missing observations.

The submitted report predates some of this documentation. In particular, the current source registry identifies the imports series as OECD data distributed through FRED (`XTIMVA01ESM667S`). For the current methodology, data sources and interpretation of results, refer to the repository `README.md` and `data/source_manifest.csv`.
